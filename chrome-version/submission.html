form_submission

这是一个 真实可运行 的 demo:当你聚焦下方输入框时,页面会动态注入一条 prerender 规则,并带上 form_submission: true,让浏览器把搜索结果页作为 表单提交形式 预渲染。点击「搜索」提交表单时,已准备好的 prerender 会被瞬间激活。

  "prerender": [
    {
      "form_submission": true,
      "urls": ["search.html?q=..."]
    }
  ]
}
